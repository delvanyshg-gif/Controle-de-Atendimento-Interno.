# Controle-de-Atendimento-Interno.
Sistema de Controle de Atendimento Interno (MVP Front-End) desenvolvido em HTML, CSS e JS para centralizar solicitações, padronizar processos e melhorar a comunicação entre setores. Projeto da UC Desenvolvimento de Sistemas (Turma 1736 / Equipe 01) utilizando metodologia ágil Scrum.
