# Atende+ — MVP de Controle de Atendimento Interno

O **Atende+** é um protótipo de sistema para organizar solicitações internas, acompanhar o status dos chamados e oferecer uma central de suporte.

## Objetivo

Centralizar o registro e a consulta de solicitações em uma interface simples, responsiva e fácil de usar.

## Funcionalidades

- **Início:** visão geral e atalhos.
- **Dashboard:** indicadores e solicitações recentes.
- **Solicitações:** cadastro, consulta e atualização de status.
- **Suporte:** registro de dúvidas e problemas técnicos.
- **Configurações:** personalização de tema e preferências locais.
- **FAQ / Ajuda:** perguntas frequentes e orientações.
- **Login e cadastro:** telas de acesso da versão demonstrativa.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- localStorage
- Git e GitHub

## Status do projeto

**MVP em desenvolvimento.**

A versão atual utiliza armazenamento local no navegador. Um backend será necessário para autenticação segura, centralização dos dados e sincronização entre diferentes computadores.
